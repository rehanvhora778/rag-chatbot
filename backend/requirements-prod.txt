# ============================================================
# Production requirements (Render / any Linux host)
# ============================================================
# Same as requirements.txt, with two deliberate differences:
#
#   1. gunicorn is added — the WSGI server that runs Django in production.
#      `manage.py runserver` is a development server and must never be used.
#
#   2. sentence-transformers is REMOVED. It exists only as the fallback
#      embedding backend (EMBEDDING_BACKEND=torch) and drags in PyTorch, which
#      is ~520 MB on its own — more than a free-tier build can comfortably hold.
#      The default ONNX backend produces identical vectors, so nothing changes
#      except the install size. `transformers` and `huggingface_hub` are listed
#      explicitly here because the ONNX backend needs them (tokenizer + model
#      download) and they used to arrive as sentence-transformers dependencies.
#
# Install with:  pip install -r requirements-prod.txt
